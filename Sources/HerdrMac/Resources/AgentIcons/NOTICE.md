# Agent mark attribution and licensing

This folder contains 21 product marks used to identify agents in uHerdr. The generic ✦ fallback is drawn by the app and is not a bundled brand image.

The marks identify Antigravity CLI (Google), Amp, Claude Code, Cline, Codex (OpenAI), GitHub Copilot CLI, Cursor Agent CLI, Devin CLI (Cognition), Droid (Factory), Gemini CLI, Grok CLI (xAI), Hermes Agent (Nous Research), Kilo Code CLI, Kimi Code CLI (Moonshot), Kiro CLI (AWS), Letta Code, Maki, OpenCode, Pi, Qoder CLI, and Qwen Code (Alibaba). [SOURCES.md](SOURCES.md) records the product page, original asset URL, and adaptations for every bundled file.

Copyright in each image remains with its respective rights holder. Product names and marks remain the trademarks of their respective owners. Their inclusion identifies the agents; it does not imply sponsorship or endorsement of uHerdr.

These images are third-party artwork and are not covered by uHerdr's MIT license. No asset-specific redistribution license or permission grant was recorded with the downloaded marks. The source URLs are attribution, not a grant of rights. Redistribution remains subject to the applicable owners' asset and brand terms; this notice does not grant permission to reuse the marks.

The files were scaled to at most 64 pixels. Some source images were rendered from SVG, and the OpenAI mark's background circle was removed. uHerdr draws the white-only marks in the current text color. The per-file source notes describe these adaptations.
