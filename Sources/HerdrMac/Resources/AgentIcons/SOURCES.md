# Agent icons

Official marks for the coding agents herdr detects, shown beside agent names in uHerdr. Each mark belongs to its owner. Files are named by herdr agent id, scaled to at most 64 px; agents without a file (such as `muse`) use the generic ✦ symbol. Sources checked 2026-10-04.
