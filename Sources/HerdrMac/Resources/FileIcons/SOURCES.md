# File icons

SVG icons from [Material Icon Theme](https://github.com/material-extensions/vscode-material-icon-theme) v5.39.0, fetched unchanged from the `icons/` folder of that tag. MIT licensed; the notice is in `docs/licenses/MaterialIconTheme-LICENSE` and ships in the app as `MaterialIconTheme-LICENSE`.

`folder.svg` is the theme's `folder-base.svg` with its overlay shape removed and the folder colour set to the theme's default folder grey (`#90a4ae`).

To add an icon, copy it from the same tag and map a name or extension to it in `Sources/HerdrCore/FileIconName.swift`.
