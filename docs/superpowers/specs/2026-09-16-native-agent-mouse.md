# Native agent mouse and clipboard

Enable Claude Code's own fullscreen mouse selection and copy-on-release using an unmodified Herdr 0.9.0 server. Keep native Shift-drag selection and all existing keyboard, paste, resize, reconnect, scrollback, and remote-device behavior.

Use Herdr's direct binary terminal protocol (version 22) for the same terminal control connection. Unlike the JSON CLI wrapper, consume MouseCapture messages and send structured AttachMouse events so the server applies the application's real mouse mode. Continue replaying complete ANSI frames through Ghostty. Gate the new transport on the server snapshot's protocol version; unsupported versions use the existing CLI bridge.

Herdr routes OSC 52 clipboard writes only to its foreground client shell. The selected native pane therefore owns one auxiliary client-shell connection once its focused application captures the mouse, until focus or visibility is lost. Negotiate endpoint generation 1 with graphics disabled, follow the pane using pane.focus through the endpoint, and accept clipboard events only from that active connection. Protocol 22 does not identify the originating pane in clipboard messages: as with the stock client, a background pane can send a clipboard write to the foreground client. Close the auxiliary connection when focus/visibility changes. Direct terminal resize ownership remains authoritative. Check directly controlled pane size preservation and focus loss in live tests. Stock protocol 22 offers no clipboard-only shell: its active shell can resize unmounted tabs without direct resize locks. Document this limitation rather than claim their geometry is preserved. Never replace the server or spawn substitute shells.

The binary framing and decoder must enforce length bounds, validate expected message structure, and ignore unrelated known side effects. Connections use ordered writes, finite connection/write deadlines, and deterministic shutdown. Late callbacks are rejected by connection generation. Input and clipboard errors remain visible. Preserve clipboard-read denial. The native view advertises cell-coordinate SGR mouse capture; the transport converts complete reports to structured events, including motion, drag, release, and modifiers.

Validation: wire codec/fragmentation tests; a disposable stock-server fixture that requires press/drag/release then emits OSC 52; production SwiftUI/Ghostty event injection; Shift-drag local copying; mode-only disable, reconnect, resize, and pane preservation; existing native keyboard/paste/URL tests; actual Claude Code fullscreen selection if the installed authenticated CLI can be exercised without submitting a prompt. Clipboard tests save and restore the user's pasteboard.
